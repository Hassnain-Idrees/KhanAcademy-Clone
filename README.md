# KhanAcademy Clone

A practice clone of the Khan Academy web app, built for learning and as part of a lab/project exercise. The goal of this project is to recreate basic Khan Academy UI components and structure for frontend practice.

---

## 🧰 Features

- Responsive **HTML & CSS** layout mimicking Khan Academy’s design  
- Basic navigation and page structure with a home-like layout  
- Structured content area to represent courses or featured sections  
- Clean design using common web layout patterns
